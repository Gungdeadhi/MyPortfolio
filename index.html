VAE Synthetic Data for Generalizable Occupancy Detection IoT System with CIMA+Random Forest

Anak Agung Gede Mahawira Adhi Putra, Aji Gautama Putrada, Nur Ghaniaviyanto Ramadhan

Abstract

Internet of Things (IoT) occupancy detection is one way to achieve cost savings in smart buildings. However, generalizability issues indicate that machine learning models used in one occupancy detection case study may perform poorly in another. The purpose of this study is to address that issue using synthetic data generated by a variational autoencoder (VAE). The first stage is to collect a dataset with two PIR sensors and two ultrasonic sensors through an IoT system we developed. The collected data will then undergo preprocessing and labeling of room conditions, namely, busy and quiet. Next, the random forest is used to predict labels and is evaluated using accuracy, precision, and F1-score as metrics. We then generated the synthetic dataset using VAE and conducted a perturbation-robustness test to assess the generalizability of both datasets. Finally, we observed changes in the performance of both machine learning models when using the new dataset. We also used a classification-integrated moving average (CIMA) to improve the predictive ability of the models in this sequential classification case study and the Pearson correlation coefficient (PCC) to measure optimal sensor placement for occupancy detection. The test results show that CIMA combine with random forest on VAE synthetic data exhibits better generalizability in the perturbation robustness test, with a smaller slope and a larger intercept equal with negative 0.34 and positive 0.98, respectively. The performance test results show that CIMA combine with random forest is the optimal method for occupancy detection, with accuracy, precision, recall, and F1score all at 0.98.
